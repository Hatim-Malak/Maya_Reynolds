# Dr. Maya Reynolds — Therapy Website

A premium, bespoke website built for a private-practice clinical psychologist. The design prioritizes a calm, editorial, and trustworthy aesthetic, moving away from generic corporate healthcare templates to create a truly warm and human user experience.

## ✨ Features

- **Editorial Design Language:** Generous whitespace, asymmetrical layouts, and elegant serif typography.
- **Responsive Architecture:** Fully optimized for all devices, from ultra-wide desktops to small mobile screens.
- **Subtle Micro-Interactions:** Buttery-smooth hover states, slow image scaling, and delicate transitions to maintain a calm browsing experience.
- **Component-Driven:** Built modularly with a suite of custom React components (Hero, Who We Help, Areas of Expertise, Our Office, etc.).

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Fonts:** Lora (Serif), Geist (Sans), Alex Brush (Cursive Accent)

## 🎨 Design Identity

- **Color Palette:**
  - `Accent/Background`: Soft Cream / Sage Green (`#e6f2dd`)
  - `Primary`: Deep Teal / Green (`#659287`)
  - `Secondary`: Muted Green (`#88bda4`)
  - `Foreground`: Charcoal / Soft Black (`#383633`)
- **Vibe:** Calm, Warm, Trustworthy, Human, Professional.

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Hatim-Malak/Maya_Reynolds.git
   ```
2. Navigate into the frontend directory:
   ```bash
   cd Maya_Reynolds/frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
